# 互动式建筑资源卡设计

## 目标

在保留现有英语学习资源首页结构、筛选方式和数据能力的前提下，把普通资源网格改造成更有趣的混合建筑界面。每个网站表现为一座可选择的小建筑；选择建筑后，网站详情以悬浮闪卡出现，再由用户主动进入外部网站。

目标用户仍是成人英语自学者。设计需要有趣但不幼稚，不能降低资源查找效率，也不能影响投稿、审核和外部链接安全。

## 体验范围

- 保留顶部介绍、搜索框、分类筛选、水平筛选和价格筛选。
- 每个网站仍占据资源网格中的一个位置，但视觉载体由矩形卡片变为独立建筑。
- 不增加地图、独立房间页面、角色移动、积分或游戏任务。
- 不改变资源、投稿和审核的数据模型与服务端流程。

## 建筑语言

建筑使用轻量 CSS 与内联 SVG 组合完成，延续当前站点的颜色、圆角和编辑感，同时增加屋顶、门窗、招牌、烟囱和灯光等结构。

不同分类对应不同建筑原型：

| 分类 | 建筑原型 |
| --- | --- |
| 综合 | 学习中心 |
| 听力 | 钟楼 |
| 口语 | 咖啡木屋 |
| 阅读 | 书店 |
| 写作 | 写作工坊 |
| 词汇语法 | 语言研究所 |
| 职场 | 办公楼 |
| 雅思 | 学院城堡 |
| 托福 | 国际学院 |
| GitHub Skills | 发明工坊 |

同类资源共享基本轮廓，通过稳定的颜色变体、窗户布局和招牌内容避免机械重复。网站名称显示在建筑招牌上，技能和价格作为建筑脚下的简短信息出现。

## 核心交互

1. 用户通过搜索或筛选找到建筑。
2. 点击建筑或用键盘激活建筑后，建筑进入选中状态：门窗亮起并产生短暂的轻微上浮效果。
3. 网站详情闪卡从建筑侧边浮出，内容包括网站名称、技能、简介、适合水平、价格、可选的“2026 更新”标识，以及“进入网站”按钮。
4. 点击“进入网站”后，以现有安全属性在新标签页打开外部链接。
5. 同一时间只允许展开一张闪卡。选择另一座建筑会关闭前一张并打开新闪卡。
6. 再次点击当前建筑、点击资源网格空白处或按 Esc，关闭闪卡。
7. 搜索条件或筛选条件改变后，当前闪卡自动关闭，避免展示已经不在结果中的资源。

## 响应式布局

桌面端优先把闪卡放在建筑右侧；空间不足时改为左侧，确保内容不超出视口。闪卡具有明确层级，但不会永久遮住其他建筑。

移动端不使用侧边悬浮，闪卡在选中建筑下方展开，并占满该网格列宽。页面不出现横向滚动，按钮保持适合触控的尺寸。

## 动效与可访问性

- 动画只用于门窗亮起、建筑轻微上浮和闪卡淡入位移，持续时间短，不加入循环动画。
- 当系统启用 `prefers-reduced-motion` 时，取消位移和上浮，只保留即时状态变化。
- 建筑入口使用真实按钮语义，具有可见焦点、展开状态和关联面板属性。
- 闪卡关闭后，焦点返回触发它的建筑；Esc 可以关闭。
- 不依赖颜色表达选中状态，建筑高亮同时包含轮廓、灯光和展开状态。

## 组件边界

- `BuildingResourceCard`：负责单个建筑入口、选中视觉和闪卡锚点。
- `BuildingIllustration`：根据资源分类渲染建筑原型与稳定变体，不包含业务行为。
- `ResourceFlashcard`：展示现有资源详情和外部访问按钮。
- `ResourceDirectory`：继续负责搜索与筛选，并新增唯一展开资源的状态与关闭规则。
- 独立映射模块负责“资源分类 → 建筑原型”，使视觉映射可以单独测试和调整。

## 状态与错误处理

资源仍由现有静态目录和资源接口合并产生。建筑表现只消费 `Resource` 数据，不改变接口。

资源为空时继续显示现有空状态。缺少可选更新日期时不显示更新标识。建筑样式映射遇到未知分类时使用“学习中心”作为安全回退。外部链接行为沿用 `target="_blank"` 与 `rel="noopener noreferrer"`。

## 测试与验收

- 分类能够映射到预期建筑原型，未知值使用安全回退。
- 点击建筑会展示对应网站的闪卡，点击另一建筑会切换内容。
- 再次点击、点击空白处和按 Esc 能关闭闪卡。
- 搜索或筛选变化会关闭已展开闪卡。
- 闪卡中的外部链接地址和安全属性正确。
- 原有资源筛选、投稿表单和首页基础测试继续通过。
- 生产构建成功，桌面和移动布局没有横向溢出。

## 不在本次范围

- 真实 3D、Canvas 游戏地图或角色控制。
- 用户账号、收藏、积分、学习进度或社交聊天。
- 为每个网站制作独立建筑图片。
- 修改投稿、审核、数据库或部署访问权限。
